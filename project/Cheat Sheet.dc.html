Git cheat sheet

THE 80% YOU USE DAILY

Pin this. Column order follows a real working session: set up → daily loop → branches → fixing mistakes.

1Start
git init
new repo in this folder
git clone URL
copy an existing repo
git remote -v
where push/pull go
Mnemonic
Add → Commit → Push. "All Cats Pounce." That's the daily loop.
2Daily loop
git status
what changed, what's staged
git add -p
stage hunk by hunk — review as you go
git commit -m "msg"
snapshot the staged set
git pull --rebase
get teammates' commits first
git push
publish your commits
3Branches
git switch -c feat/x
create + move to a branch
git switch main
jump back
git merge feat/x
weave a branch into this one
git branch -d feat/x
delete merged branch
git log --oneline --graph
see the shape of history
4Oh no
git restore file
discard unstaged edits
git restore --staged file
un-stage, keep edits
git commit --amend
fix the last commit / message
git revert SHA
undo publicly, safely
git reflog
the "undelete" of last resort
Danger zone
reset --hard and push --force destroy work. Never on shared branches.
