A field guide to data shapes

Four structures, drawn the way you should picture them. Each card answers the same three questions: what does it look like, what's instant, what's slow.

Arraya row of numbered boxes
FASTJump to any index — a[2] is one hop, O(1)
SLOWInsert at the front — every box shifts right, O(n)
Linked lista treasure hunt of pointers
FASTInsert/remove at a known spot — re-aim two pointers, O(1)
SLOWFind item #k — walk the chain from the head, O(n)
Hash mapa coat check with math
FASTGet/set by key — the hash computes the shelf number, O(1)
SLOW"Smallest key?" — no order at all, scan everything, O(n)
Binary search treesmaller left, bigger right
FASTSearch sorted data — halve at every level, O(log n)
SLOWInsert in sorted order (1,2,3…) — it degrades into a list, O(n)
The one-question picker: need order? Array (by position) or BST (sorted). Need lookup by name? Hash map. Need cheap inserts mid-sequence? Linked list. Say the need out loud and the structure picks itself.
