DESIGN PATTERNS · CH. 3

The Decorator Pattern — Starbuzz Coffee

Starbuzz's menu has a handful of beverages and a pile of condiments — milk, mocha, soy, whip. Model every combination as a subclass and you get a class explosion: hundreds of HouseBlendWithSoyAndMochaAndWhip classes. Decorator wraps a drink in condiment objects that each add their own cost, so any order is built at runtime by nesting wrappers.

Core idea

What is the Decorator pattern — and why is it the pattern behind Java's InputStream chain?

The Decorator pattern attaches additional responsibilities to an object dynamically, as an alternative to subclassing. Each decorator implements the same interface as the thing it wraps, delegates to it, and adds its own behavior on top:

Each condiment only knows its own delta and the object it wraps — Mocha.cost() returns wrapped.cost() + 0.20. Stack four wrappers and the constructor nests the same way the receipt does:

new Mocha(new Whip(new Soy(new HouseBlend())))
Open/Closed Principle: classes should be open for extension but closed for modification. Every condiment is a new class added beside Beverage — nothing about HouseBlend ever changes.

The same shape, three places you already use it

Java's I/O stack
Each stream wraps the last, adding one job — buffering, then typed reads.
FileInputStream ↓ Buffered ↓ DataInputStream
Spring Security's filter chain
Each filter wraps the request, layering in auth, headers, and session state before the controller ever sees it.
Request ↓ AuthFilter ↓ SecurityWrapper
A CIAM REST client
Logging, metrics, and circuit-breaking layered over the real client — none of them touch it.
RealClient ↓ CircuitBreaker ↓ LoggingClient

Main.java
public class Main {
  static abstract class Beverage {
    abstract String getDescription();
    abstract double cost();
  }
  static class Espresso extends Beverage {
    String getDescription() { return "Espresso"; }
    double cost() { return 1.99; }
  }
  static abstract class CondimentDecorator extends Beverage {
    Beverage wrapped; // IS-A Beverage, HAS-A Beverage
    CondimentDecorator(Beverage b) { wrapped = b; }
  }
  static class Mocha extends CondimentDecorator {
    Mocha(Beverage b) { super(b); }
    String getDescription() { return wrapped.getDescription() + ", Mocha"; }
    double cost() { return wrapped.cost() + 0.20; } // delegate then add
  }
  static class Whip extends CondimentDecorator {
    Whip(Beverage b) { super(b); }
    String getDescription() { return wrapped.getDescription() + ", Whip"; }
    double cost() { return wrapped.cost() + 0.10; }
  }
  public static void main(String[] args) {
    Beverage order = new Whip(new Mocha(new Mocha(new Espresso())));
    System.out.println(order.getDescription());
    System.out.printf("total: $%.2f%n", order.cost());
    // Add your own decorator (Soy? Caramel?) and re-run.
  }
}
