Every term gets three things: a plain-English definition, the sentence you'll actually hear at work, and what it is not.

A
API /ˌeɪ piː ˈaɪ/ · Application Programming Interface WEB

A menu of things one program lets other programs ask it to do. The menu says what you can order (endpoints), how to ask (requests), and what comes back (responses) — without showing you the kitchen.

Heard at work: "Does the payments API have an endpoint for refunds?"
Not: a database, a server, or a website — those may sit behind an API.
Argument vs. parameter — the classic mix-up LANGUAGE BASICS

The actual value you pass into a function when calling it. The parameter is the named slot in the function's definition; the argument is what fills it.

def greet(name):  # name = parameter
greet("Ada")       # "Ada" = argument
Async asynchronous execution EXECUTION MODEL

Starting a slow job (network call, file read) and doing other work while it finishes, instead of standing still. Like ordering at a food truck and sitting down — the buzzer (callback/promise) tells you when it's ready.

Heard at work: "That endpoint is slow — make the fetch async so the UI doesn't freeze."
Not: parallel. One cook can run async; parallel means more cooks.
